01 / Application DevelopmentAlexander Hills

Building FindIt SDSU: From an Idea to a Working Application

By Alexander Hills

For FindIt SDSU, I took responsibility for developing the main web application and integrating the SQLite database. I wanted to build something that went beyond a basic database assignment, so I focused on features like reporting lost and found items, uploading photos, searching through reports, and finding possible matches. One of the biggest improvements was making the matching system more specific, so it wouldn't suggest completely different items just because they shared a color or category. I also worked on connecting the claim process to the database so records update correctly when an item is returned. What I like about this project is that we're applying what we learned in CS 514 to something students could actually use on campus. There's still room to improve it, but our goal was to create a working prototype that feels like a real application.

02 / Database & Quality AssuranceAndy Thai

Making Sure the Database Works Behind the Scenes

By Andy Thai

For FindIt SDSU, my main focus has been testing the application and helping with the database design. Since the website handles lost and found reports, photos, and claims, it's important that all the information is stored correctly and that the different parts of the database work together. I've been focusing on checking the relationships between tables, reviewing the SQL queries, and making sure the application handles situations like multiple people claiming the same item. One thing that makes our project interesting is that it doesn't just store lost and found posts. It also tries to connect related reports and keeps track of the claiming process. I think this project is a good way for us to apply the database concepts we've learned in CS 514 to a real-world problem.

03 / Documentation & PresentationSamuel Shadi

Bringing the FindIt SDSU Project Together

By Samuel Shadi

For FindIt SDSU, my role has been focused on the documentation, presentation, and explaining how our project works. We wanted to create something that students could actually find useful, rather than just building a database for an assignment. The idea behind FindIt SDSU is pretty simple: instead of relying on social media posts or asking around campus, students would have one place to search for lost belongings or report something they've found. What I like about our project is how we combined a working website with database features like item searching, matching, and claim tracking. My goal has been to help communicate those features clearly through our project materials so people can understand both how the application works and why it could be useful.
