01 / Application & schema

Alexander Hills

Draft supplied by Alexander · personal review required before class submission

For FindIt SDSU, I took responsibility for developing the main web application and integrating the SQLite database. I wanted to build something that went beyond a basic database assignment, so I focused on features like reporting lost and found items, uploading photos, searching through reports, and finding possible matches. One of the biggest improvements was making the matching system more specific, so it wouldn't suggest completely different items just because they shared a color or category. I also worked on connecting the claim process to the database so records update correctly when an item is returned. What I like about this project is that we're applying what we learned in CS 514 to something students could actually use on campus. There's still room to improve it, but our goal was to create a working prototype that feels like a real application.
