Run it yourself

Local setup.

Use Python 3.12 and fictional data. The local development demo needs no presenter password; public hosting requires the security settings in the deployment guide.

Deployment guide ↗
git clone https://github.com/DellyCodez/FindIt-SDSU.git
cd FindIt-SDSU
git switch --track origin/work/unified-site
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m app.init_db
.venv/bin/python run.py

Then open http://127.0.0.1:5000/. On Windows, use the PowerShell commands in the README.
