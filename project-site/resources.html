Run it yourself

Local setup, from the real application branch.

Use Python 3.12. These commands follow the tested application README. Keep demo data fictional; the reviewer is local-only and has no production authentication.

Full macOS, Linux, and Windows instructions ↗
git clone https://github.com/DellyCodez/FindIt-SDSU.git
cd FindIt-SDSU
git switch --track origin/work/app
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m app.init_db
.venv/bin/python run.py

Then open http://127.0.0.1:5000/. If work/app is already checked out locally, use git switch work/app instead of the tracking command.
